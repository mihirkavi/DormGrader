# DormGrader

DormGrader is a USC Housing mobile-application project focused on helping students evaluate and compare campus housing options.

## Repository contents

This repository preserves the project-management package developed for USC ISE 515, including:

- the final project report and presentation
- business-case and NPV analysis
- project charter, work breakdown structure, schedule, and budget
- risk, resource, stakeholder, and change-management planning
- a lightweight website prototype in `index.html`

## Status

DormGrader is an academic product concept and project-planning archive, not a maintained production service.
